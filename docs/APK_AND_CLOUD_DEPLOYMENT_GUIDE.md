# الدليل الفني الشامل: النشر السحابي (Cloud Deployment) وتوليد تطبيق أندرويد (APK)

هذا الدليل يوضح لحضرتك خطوة بخطوة كيفية نقل منصة **TEACHER OS** لتعمل سحابياً 24/7 بكامل كفاءتها، وكيفية استخراج ملف التطبيق بصيغة **APK** لهواتف الأندرويد ليعمل مرتبطاً بالسيرفر السحابي.

---

## 🧭 الجزء الأول: كيف يعمل النظام سحابياً بكامل كفاءته؟ (The Cloud Architecture)

لكي يعمل التطبيق على هواتف المدرسين والطلاب وأولياء الأمور من أي مكان (سواء شبكة واي فاي أو باقة موبايل)، ينقسم النظام إلى شقين:

```
[ هاتف الطالب / المدرس / ولي الأمر ]
           ▲
           │ (تطبيق APK أو رابط PWA)
           ▼
[ سيرفر سحابي 24/7 مع دومين HTTPS ] ◄──► [ قاعدة البيانات والذكاء الاصطناعي ]
  (Render / Hetzner / DigitalOcean)          (SQLite / PostgreSQL + Gemini)
```

### 1. خطوات النشر السحابي (3 خطوات بسيطة):

#### أ. اختيار واستئجار الخادم السحابي:
يمكن استخدام أحد الخيارات السريعة التالية:
1. **الخيار الأسهل والجاهز (PaaS):** مثل **Render.com** أو **Railway.app** (يدعم Node.js بنقرة واحدة ويوفر دومين مجاني بشهادة SSL فورية).
2. **الخيار الاحترافي (VPS):** خادم خاص افتراضي على **Hetzner** أو **DigitalOcean** (بتكلفة 4 إلى 6 دولارات شهرياً)، نظام تشغيل Ubuntu 22.04.

#### ب. رفع الكود وتشغيله عبر مدير العمليات (PM2):
على السيرفر، يتم نسخ ملفات المشروع وتشغيل الخادم ليعمل باستمرار دون توقف:
```bash
# تثبيت مدير العمليات PM2
npm install -g pm2

# تشغيل السيرفر السحابي
pm2 start backend/src/server.js --name "teacher-os"

# ضمان إعادة التشغيل التلقائي عند إعادة إقلاع السيرفر
pm2 startup
pm2 save
```

#### ج. ربط الدومين وتفعيل شهادة التشفير (SSL / HTTPS):
* نظام أندرويد يفرض أن تكون كافة الاتصالات مشفرة بـ **HTTPS**.
* عند ربط النطاق (مثلاً `app.teacher-os.com`)، يتم تفعيل شهادة SSL مجانية عبر **Certbot (Let's Encrypt)**:
```bash
sudo certbot --nginx -d app.teacher-os.com
```

## 📱 الجزء الثاني: كيفية استخراج التطبيق بصيغة APK

لقد قمنا بتجهيز بيئة المشروع وتزويدها بكافة المقومات التقنية، ولديك **3 طرق رسمية ومضمونة** للحصول على ملف الـ APK:

---

### 🌟 الطريقة الأولى (الموصى بها بشدة للمنصات التعليمية): أداة Google PWA Builder
لقد قمنا ببرمجة وربط ملفي `manifest.json` و `sw.js` داخل كود المنصة، مما جعلها **تطبيق ويب تقدمي معتمد (PWA)** بمقاس طولي مخصص للموبايل.

**خطوات استخراج الـ APK في دقيقة واحدة:**
1. ارفع موقعك السحابي برابط HTTPS (مثال: `https://app.teacher-os.com`).
2. ادخل على أداة مايكروسوفت وجوجل الرسمية: [PWABuilder.com](https://www.pwabuilder.com/).
3. ضع رابط موقعك واضغط **Start**.
4. سيتحقق النظام من أن التطبيق جاهز 100%، ثم اضغط على زر **Package for Android**.
5. ستضغط زر **Generate APK** لتحميل ملف الـ `APK` النهائي فورياً وموقعاً بشهادة أمان رسمية، جاهز للتثبيت على أي موبايل أو للرفع على متجر Google Play!

> [!TIP]
> **أهم ميزة سحرية لهذه الطريقة:**
> أي ميزة أو سؤال تصويت أو تعديل تجريه على السيرفر السحابي يظهر **تلقائياً وفورياً** داخل تطبيق الهاتف لجميع الطلاب دون أن تطلب منهم إعادة تحميل أو تحديث ملف الـ APK!

---

### 🛠️ الطريقة الثانية: مشروع أندرويد المدمج الجاهز (`android/`)
لقد أنشأنا لحضرتك داخل المشروع مجلداً كاملاً باسم `android/` يحتوي على تطبيق أندرويد متكامل ومبني بـ Java و Android SDK.

**المميزات المدمجة في هذا التطبيق:**
* شاشة كاملة مع تسريع عتادي (Hardware Acceleration).
* صلاحية الكاميرا الكاملة لتصوير أوراق الامتحانات واستخدام المصحح الضوئي (OCR).
* صلاحية المايكروفون لحضور حصص الزووم المباشرة وتسجيل الكبسولات الصوتية.
* سحب الشاشة للأسفل للتحديث (Pull-to-Refresh).

**خطوات توليد الـ APK عبر Android Studio:**
1. افتح برنامج **Android Studio** واختر **Open Existing Project** وحدد مجلد `android`.
2. في ملف `MainActivity.java`، استبدل الرابط برابط موقعك السحابي:
   ```java
   public static final String PRODUCTION_CLOUD_URL = "https://app.teacher-os.com";
   ```
3. من القائمة العلوية، اختر:
   **Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)**.
4. خلال ثوانٍ سيظهر لك إشعار: *"APK(s) generated successfully"* مع رابط للوصول لملف `app-debug.apk` أو `app-release.apk`.

---

### 🚀 الطريقة الثالثة: بناء تطبيق Flutter الأصلي (`mobile/`)
إذا كنت تفضل بناء تطبيق فلاتر المكتوب بلغة Dart والموجود في مجلد `mobile/`:

1. افتح ملف `mobile/lib/core/network/api_client.dart`.
2. غيّر قيمة `baseUrl` إلى رابط سيرفرك السحابي:
   ```dart
   static const String baseUrl = 'https://api.teacher-os.com';
   ```
3. في التيرمينال، اكتب الأمر التالي:
   ```bash
   cd mobile
   flutter build apk --release
   ```
4. ستجد ملف الـ APK الناتج في المسار:
   `mobile/build/app/outputs/flutter-apk/app-release.apk`.

---

## 📲 التثبيت المباشر بدون APK (اختياري وسريع جداً):
لأن التطبيق يدعم تقنية PWA؛ يمكن لأي طالب أو مدرس فتح الرابط من متصفح الموبايل (Chrome أو Safari) والضغط على خيارات المتصفح ثم:
**«إضافة إلى الشاشة الرئيسية» (Add to Home Screen / Install App)**
سيتم تثبيت أيقونة التطبيق باسم **Teacher OS** وتعمل كأنه تطبيق APK تم تنزيله من المتجر تماماً بدون أي اختلاف!
