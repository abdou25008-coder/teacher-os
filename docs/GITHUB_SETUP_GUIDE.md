# دليل النشر الدائم على GitHub ومنصة المعاينة السحابية (GitHub Pages & Releases)

هذا الدليل يشرح لحضرتك بالتفصيل كيف تجعل منصة **TEACHER OS** تمتلك **رابطاً دائماً ومتاحاً 24 ساعة على موقع GitHub** لمشاركة الكود، ومعاينة المنصة من أي هاتف، وتنزيل تطبيق أندرويد (APK) الجاهز تلقائياً.

---

## 🌟 ما الذي ستحصل عليه برابط GitHub الدائم؟

1. **رابط المستودع الدائم للكود (GitHub Repository):**
   * رابط مثل: `https://github.com/حسابك/teacher-os`
   * يمكنك من خلاله حفظ كل كود المنصة سحابياً، مشاركته مع فريق عملك، أو ربطه بأي خادم سحابي عالمي (مثل Render أو DigitalOcean).

2. **رابط المعاينة الدائم المباشر (GitHub Pages Web Preview):**
   * رابط مثل: `https://حسابك.github.io/teacher-os/`
   * يتيح لأي شخص فتح التطبيق من متصفح الهاتف أو الكمبيوتر في أي وقت دون الحاجة لتشغيل حاسوبك الشخصي إطلاقاً!

3. **رابط تنزيل تطبيق أندرويد APK الدائم (GitHub Actions CI/CD):**
   * من خلال ملف العمل المؤتمت `.github/workflows/build-apk.yml`، يقوم سيرفر GitHub ببناء ملف الـ APK تلقائياً وإتاحته للتنزيل المباشر فورياً.

---

## 🚀 الخطوات العملية لنشر المشروع (في 3 خطوات بسيطة):

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. افتح متصفحك وادخل على صفحة إنشاء مستودع جديد:
   👉 **[https://github.com/new](https://github.com/new)**
2. في خانة **Repository name**، اكتب: `teacher-os`
3. اختر نوع المستودع: **Public** (عام) أو **Private** (خاص حسب رغبتك).
4. اضغط على الزر الأخضر في الأسفل: **Create repository**.
5. بعد الإنشاء، انسخ الرابط الذي يظهر لك، ويكون بصيغة:
   `https://github.com/اسم-حسابك/teacher-os.git`

---

### الخطوة 2: رفع المشروع بنقرة واحدة عبر السكربت الذكي
لقد أنشأنا لحضرتك أداة نشر مخصصة داخل مجلد المشروع لتسهيل العملية دون الحاجة لكتابة أوامر معقدة:
1. افتح مجلد المشروع `teacher-os`.
2. اضغط مرتين على ملف: **`publish_to_github.bat`**.
3. سيقوم السكربت بالتحقق من Git وحفظ ملفات المنصة بالكامل.
4. عندما يطلب منك السكربت: *"الصق رابط المستودع هنا"*:
   * اضغط كليك يمين للصق رابط مستودعك الذي نسخته في الخطوة 1 ثم اضغط **Enter**.
5. سيتم رفع كافة الأكواد والملفات إلى GitHub في ثوانٍ معدودة!

*(ملاحظة: إذا ظهرت لك نافذة منبثقة من متصفحك لتسجيل الدخول إلى GitHub، اضغط Sign in with browser لإعطاء الصلاحية).*

---

### الخطوة 3: تفعيل رابط المعاينة السحابي الدائم (GitHub Pages)
لكي يعمل رابط المعاينة المباشر على الهاتف والحاسوب:
1. ادخل على صفحة مستودعك على GitHub.
2. اضغط على التبويب العلوي: **Settings** (الإعدادات).
3. من القائمة الجانبية اليسرى، اختر: **Pages**.
4. تحت قسم **Build and deployment**:
   * في خانة **Source**، اختر: **GitHub Actions**.
5. سيتم تلقائياً إطلاق عملية النشر السحابية وسيعطيك الرابط المباشر الدائم:
   `https://<username>.github.io/teacher-os/`
   افتح هذا الرابط من هاتفك وستجد واجهة المنصة كاملة وتدعم التثبيت المباشر على الهاتف (Add to Home Screen)!

---

### الخطوة 4: تنزيل ملف الـ APK التلقائي
1. من أعلى صفحة المستودع على GitHub، اضغط على تبويب **Actions**.
2. ستجد عملية باسم **Build Android APK** تعمل تلقائياً.
3. بعد اكتمالها، اضغط عليها وستجد ملف الـ **teacher-os-android-apk** متاحاً للتنزيل مباشرة بصيغة ZIP يحتوي على ملف الـ APK لتثبيته فوراً على أي موبايل أندرويد!

---

## 💻 الأوامر اليدوية (للمطورين - Alternative Manual Commands):

إذا كنت تفضل كتابة الأوامر يدوياً في سطر الأوامر (Terminal):

```bash
# الانتقال لمجلد المشروع
cd teacher-os

# تهيئة مستودع جديد
git init -b main

# إضافة وتثبيت كافة الملفات
git add .
git commit -m "feat: Teacher OS Initial Release"

# ربط المستودع برابط GitHub الخاص بك
git remote add origin https://github.com/<YOUR_USERNAME>/teacher-os.git

# رفع الكود للفرع الرئيسي
git push -u origin main
```
